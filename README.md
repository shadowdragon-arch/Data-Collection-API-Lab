# SpaceX Falcon 9 First Stage Landing Prediction

## Project Overview
This project is part of the IBM Data Science Professional Certificate Capstone. The goal is to predict whether the Falcon 9 first stage will land successfully, allowing alternate launch providers to evaluate cost-competitiveness against SpaceX.

## Lab 1: Data Collection & Wrangling (API)
- Collected past SpaceX launch data using the SpaceX REST API.
- Filtered data to only include Falcon 9 launches.
- Handled missing values in core features such as payload mass.
- Exported the cleaned dataset to `dataset_part_1.csv` for downstream EDA and machine learning.
